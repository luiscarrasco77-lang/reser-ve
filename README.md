# RESER-VE

Marketplace de posadas auténticas de Venezuela — https://reser-ve.com

- **Arquitectura, base de datos, APIs y servicios:** [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md)
- **Variables de entorno:** [.env.example](.env.example)
- **Guías:** `public/docs/` (posaderos y viajeros)

```bash
npm install
vercel env pull .env.local
npm run dev
```

Todo lo que entra a `main` se despliega automáticamente en Vercel.
